# Assets and licences

All runtime assets are bundled locally under `public/assets/`. Nothing is hotlinked, and the built game works offline. Only CC0 (public domain) and CC BY (attribution) sources are used. Every CC BY work is also credited on the in-game **Credits** screen. Processing steps are documented in `scripts/asset-pipeline/`.
